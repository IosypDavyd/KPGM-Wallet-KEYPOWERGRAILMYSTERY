# Вбудований гаманець в Android-застосунку

## Що зміниться для вас
- Застосунок на телефоні відкриватиме гаманець із файлів, які лежать всередині самого застосунку, а не з опублікованого сайту.
- Гаманець, баланси, обмін, торгівля, тренування працюватимуть, навіть якщо сайт недоступний (інтернет потрібен лише для цін і балансів у мережах).
- GPT-консультант і ШІ-стратегія й надалі звертатимуться до вашого опублікованого сайту (ключ ШІ не можна класти в телефон — його вкрадуть). Якщо сайт недоступний, покажуть зрозуміле повідомлення.
- Після змін на сайті треба буде збирати новий файл .aab (оновлення вже не прилітають самі).
- Я перепакую архів для Android Studio з готовою вбудованою версією.

## Кроки
1. Увімкнути збірку сайту у вигляді окремих файлів (режим «односторінковий застосунок»), щоб з'являвся `index.html` у `dist/client`.
2. У налаштуваннях застосунку прибрати адресу опублікованого сайту — тоді він відкриває вбудовані файли.
3. Виклики GPT-консультанта і ШІ-стратегії всередині застосунку спрямувати на `https://key-pover-grail-mystery.lovable.app` (дозволити запити з застосунку).
4. Зібрати сайт, скопіювати його в Android-проєкт, збільшити номер версії (versionCode 2), перепакувати KPGM-Wallet-Mobile.zip.
5. Перевірити: вбудована версія відкривається без сайту, гаманець створюється.

## Технічні деталі
- `vite.config.ts`: `tanstackStart({ spa: { enabled: true } })` для генерації shell `index.html`.
- `capacitor.config.ts`: видалити `server.url`, лишити `androidScheme: "https"`.
- Серверні функції: у нативному середовищі (`Capacitor.isNativePlatform()`) викликати `/_serverFn` через абсолютну базову адресу опублікованого сайту; додати CORS-заголовки для origin `https://localhost`.
- `bunx cap sync android`, `android/app/build.gradle` versionCode 2 / versionName 1.1.
